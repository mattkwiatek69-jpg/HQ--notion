# Primal Health Hub: artwork still needed

None of this artwork exists yet. The hub shows a matching line symbol in its place, so nothing is broken while it is missing.

## How to make and return it

1. Generate the first food below on its own and pick the version you like. Attach that picture as the reference for every later prompt so the set matches.
2. Keep each PNG master (1024 x 1024, transparent). Name it exactly as listed.
3. Send the PNGs back. Each one is resized to a 128 x 128 transparent WebP in `health-hub/assets/icons/` and wired up with one line in `FOOD_IC` and `FOODIC` in `health-hub/index.html`.
