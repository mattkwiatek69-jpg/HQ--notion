# Primal Health Hub: artwork still to create

Nothing in the hub is broken without these. Every food now has a picture and every Library group has its illustration. What is left would make the hub richer.

## How to make and return it

1. In ChatGPT, attach one picture you already like from the pack (for example `equipment-kettlebell.png`) as the style reference.
2. Paste the prompt below, replacing `[OBJECT]` with the text in the Object column. Generate one object at a time.
3. Save each as a 1024 x 1024 transparent PNG with the file name listed, zip them and send the zip.

> Create one editorial illustration of [OBJECT] for a Raw Primal health field guide. Match the attached approved reference's painterly natural-history style, warm soft lighting, scale, perspective, and detail. Restrained olive/moss/ochre/terracotta and natural neutrals. One recognizable isolated object, around 70% of a square canvas, generous margins, transparent background, clean silhouette readable at 64px. No text, frame, badge, scenery, or dramatic shadow. High-resolution transparent PNG.

Draw the plain generic object. Leave out brand names, logos, labels and packaging text, even where the product in the hub names a brand.
